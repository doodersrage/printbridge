    Settings

    Print host

    The Ender-3 V3 SE has no network port of its own. It is reached through whatever is plugged into its USB port.

    Use the box's IP address (shown in the Creality Cloud app under the device's details). Give it a fixed IP in your router so it doesn't change. A microSD card must be in the box.

    Notifications

    Get told when a print finishes. Use an ntfy topic URL for phone push notifications, and/or a webhook URL (for example a Home Assistant webhook) that receives a JSON event.

    Email

    Gmail and Outlook need an app password rather than your normal one. Finished and stopped emails include a picture of the model.

    Home Assistant (MQTT)

    Publishes the printer to Home Assistant through your MQTT broker (for example the Mosquitto add-on). It appears automatically as an "Ender-3 V3 SE" device with temperature, progress and time-left sensors and pause/resume/cancel buttons.

    Webcam & links

    An MJPEG stream or JPEG snapshot URL from any network camera. PrintBridge relays it, so it also works when you reach PrintBridge from outside your LAN.

    Used for links in emails and in Home Assistant.

    Filament prices

    Price per kg. Saved into each material profile; costs appear on jobs sliced after you change them.

    Storage & slicer

    Detected automatically; set PRINTBRIDGE_SLICER in the container to change it.

    Backup

    Settings (including passwords), presets, profile edits, spools and print history. Jobs are not included.

      Filament spools

      PrintBridge subtracts what each print uses from the loaded spool and warns you before a print that needs more than is left. To correct the amount, weigh the spool and subtract the empty spool's weight (often printed on its side, typically 150–250 g).
